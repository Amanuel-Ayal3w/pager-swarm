# Details

The small things that make this site feel finished. People notice them without naming them; apply the ones that fit your project.

- **Frosted glass**: 8 surfaces blur what's behind them (backdrop-filter), usually headers, menus and overlays.
- **Sticky elements**: 1 element holds its place while the page scrolls (position: sticky).
- **OpenType features**: The type uses OpenType features: tabular figures. Turn on the same ones (font-feature-settings / font-variant-numeric) where the font supports them.
- **Balanced line breaks**: Headings and paragraphs wrap evenly (text-wrap: balance / pretty) on 23 elements: no lonely last words.
- **Considered underlines**: Links set their own underline offset rather than the browser default.
- **Filters**: Images and shapes are treated with brightness (79), invert (79).
- **Shaped edges and fades**: 3 clip-path shapes and 5 masks cut or fade edges instead of hard rectangles.
- **Selection colour**: Selected text is lab(100 0 0) on lab(2.86037 0.455312 0.568903) (::selection).
- **Styled scrollbars**: Scrollbars are restyled to match the interface.
